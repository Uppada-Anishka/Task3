# AES Image Encryption using Python

This project demonstrates how to encrypt image files using the AES (Advanced Encryption Standard) algorithm in Python. The program reads an image, converts it into raw byte data, encrypts it using AES-CBC mode, and stores the encrypted output in a binary file.

Features

Encrypts image files securely using AES
Uses AES-CBC mode with random IV generation
Supports secure binary storage of encrypted image data
Built using Python and PyCryptodome
Demonstrates basic cryptography concepts for cybersecurity learning

Technologies Used

Python
Pillow (PIL)
PyCryptodome

Install required libraries:

pip install pillow pycryptodome
